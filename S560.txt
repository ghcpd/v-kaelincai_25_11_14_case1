• Test coverage: unit tests for logic and E2E tests covering interactive flows and performance metrics.

## Testing scope & limitations
⚠️ Caveats:
- Network simulation is approximate and best-effort. Real CDN and browser codec behaviors differ; run in intermediate or staging environment before production rollout.
- For automated E2E reproducibility, Playwright uses a mocked player for many network conditions, ensuring deterministic event timing. This is necessary to emulate network jitter without CI-level network shaping.
- The demos use small placeholder video assets; for full validation, replace with real multi-resolution video fragments.
- Browser differences (autoplay, codec support) may require minor tweaks; Playwright tests use `muted` to allow auto-play in headless contexts.

Mitigations:
- Resume store should align to keyframes on the server, not raw timestamps (reduce resume stutter).
- Conservative adaptive switching: maintain a small buffer before upward quality switch.
- Validate user-provided notes via a backend validator to prevent malformed timestamps.
