# Project B - Enhanced Player

Usage:
1. Setup env: `./setup.sh` (or `setup.ps1` on Windows)
2. Run tests: `./run_tests.sh`

This enhanced player implements resume, playback speed controls, auto-skip learned segments, adaptive streaming simulation, and time-synced notes with hover-to-jump.

Artifacts: see `results/`, `logs/`, `screenshots/`.
